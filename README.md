# AIVTA 2026 Conference Website

**International Conference on AI Video Technology and Applications**

November 13-15, 2026 | Hefei, Anhui, China

## Overview

This is the official website for AIVTA 2026, hosted on GitHub Pages.

- **Website**: https://aivta-cn.github.io
- **Email**: adv@aivta.org

## Features

- Responsive design for desktop, tablet, and mobile
- Bilingual support (English/Chinese) with one-click language switcher
- Countdown timer to conference date
- 8 conference topic tracks with detailed sub-topics
- IEEE publication information with EI/Scopus indexing details

## Technology Stack

- Pure HTML5 + CSS3 + Vanilla JavaScript
- No build process required
- Direct deployment to GitHub Pages

## File Structure

```
aivta-cn.github.io/
├── index.html              # Homepage (generated by build.js)
├── committee.html          # Organizing committee
├── call-for-papers.html    # 8 topic areas with tabbed interface
├── submission.html         # Submission guidelines
├── registration.html       # Registration info
├── publication.html        # IEEE publication details
├── program.html            # Conference program
├── contact.html            # Contact and venue information
├── CNAME                   # Custom domain (aivta-cn.github.io)
├── build.js                # Static site builder (zero-dependency)
├── src/
│   ├── pages/              # Page content templates
│   └── partials/           # Shared head/header/footer/scripts
├── data/                   # JSON content sources (dates, topics, committee…)
├── css/
│   └── style.css           # Main stylesheet
├── js/
│   ├── main.js             # Countdown timer, mobile menu, tabs
│   └── i18n.js             # English/Chinese language switcher
├── docs/                   # Announcements and project notes
└── promo/                  # Marketing materials (posters, brochure, scripts)
```

## Development

Open any HTML file directly in a browser for local testing. No build process needed.

## Deployment

Push to the `main` branch to automatically deploy to GitHub Pages.
